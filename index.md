# Fieldwise

Dashboard gadgets for Jira Cloud that chart and summarise any field, including custom
fields. Built on Atlassian Forge, so customer data never leaves Atlassian
infrastructure.

## Apps

**Field Stats** — group a filter by any field and measure each group by count, sum,
average, median, minimum or maximum. Two fields at once give a pivot table or a stacked
chart.
